# Deskera

> Deskera is a cloud business-software suite for small and mid-sized businesses, combining ERP and accounting (Deskera Books), CRM and sales (Deskera Sales / CRM+), and HR and payroll (Deskera People). Deskera publishes a public developer documentation site covering REST APIs for all four products, a three-legged OAuth 2.0 flow with an `x-access-token` bearer header, a webhook registration API with a 22-event catalog, and separate staging and production environments.

Generated by API Evangelist from the Deskera public developer documentation and live probes on 2026-08-04. Deskera does not publish an llms.txt of its own (`/llms.txt` on the docs host returns 404).

Authentication: every endpoint requires a valid `x-access-token` request header. Tokens are issued through the OAuth 2.0 authorization-code flow; partner `client_id`/`client_secret` are requested by emailing care@deskera.com. Production API base URL is `https://bifrost-us.deskera.com`; staging is `https://api-staging.deskera.xyz`.

There is no public OpenAPI/Swagger document — the API host returns HTTP 410 "Swagger documentation endpoints are no longer supported" on every Swagger path. There is no MCP server, no A2A agent card, no `/.well-known/` discovery surface, and no documented idempotency or rate-limit contract.

## APIs

- [Deskera Books API](https://deskera.github.io/Developer-Documentation/docs/books/started): ERP and accounting — contacts, products, accounts, invoices, bills, quotations, sales and purchase orders, credit/debit notes, deposits, expenses, payments, fulfillment, shipments, stock, warehouses, MRP, taxes, journals, tenants, custom fields, reports, webhooks
- [Deskera Sales API](https://deskera.github.io/Developer-Documentation/docs/sales/started): CRM — contacts, deals, activities, campaigns
- [Deskera CRM+ API](https://deskera.github.io/Developer-Documentation/docs/crmplus/started): table, column and record model for the CRM+ workspace
- [Deskera People API](https://deskera.github.io/Developer-Documentation/docs/people/started): HR and payroll — employees, teams, shifts, attendance, leave, expenses, bank accounts, pay schedules, pay runs, payroll components, compliance
